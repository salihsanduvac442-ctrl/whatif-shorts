# Extra: submarine keeps diving (format test)

Code-made with the lemo-opuscar iso-infographic style (lemomo-ai/lemo-opuscar, MIT): falling-drop hook + splash, nonstop dive with milestone punches. Not a calendar day; published Nov 2 as an extra to test the format.
Build: clone lemo-opuscar, copy this folder to films/sub-dive-drop, add engine.js + fonts from styles/iso-infographic/demo, run build.sh (needs ffmpeg 7).
